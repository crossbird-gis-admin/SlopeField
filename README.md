# 傾斜計測マップ

1m DEM を使って、地図上で**囲んだ範囲(農地など)の傾斜**と、**引いたラインの勾配・断面**を計測するWebGISです(GitHub Pagesで動作)。
DEMはこのPCのローカルファイルを読み込み、計算はすべてブラウザの中で行います(データはどこにも送信されません)。
描いた範囲・ラインと計測結果は、作業フォルダに GeoJSON と CSV で自動保存されます。

## フォルダ構成(リポジトリ)

```
index.html        地図本体(冒頭の CONFIG だけ編集すればOK)
README.md
tools/serve.py    ローカル確認用サーバー
```

## 基本の使い方:地域ごとの「作業フォルダ」

1. PCに地域ごとのフォルダを作り、次のファイルを入れる
   - **DEM**:GeoTIFF(`.tif`)。何枚でも可(隣り合うメッシュを分けたままでOK)
   - **レイヤ**(任意):圃場の区画(ポリゴン)や農道(ライン)の `.gpkg` / `.geojson`
2. 右パネルの「**作業フォルダを選ぶ**」でそのフォルダを選ぶ(ブラウザの確認で「編集を許可」)
   - DEMとレイヤが自動で読み込まれ、その場所へ移動します
3. 範囲を囲む・ラインを引く(下記)
4. 計測は同じフォルダの `傾斜計測.geojson`(本体)と `傾斜計測.csv`(Excel用)に自動で上書き保存されます
5. 次に開いたときは「**前回のフォルダを開く**」で続きから。別の地域は「別のフォルダに切替」

```
例)C:\傾斜計測\箕輪_ほ場A\
      dem_5337xxxx.tif        ← DEM
      筆ポリゴン.gpkg          ← レイヤ(任意)
      傾斜計測.geojson         ← アプリが作る(描いた範囲・ライン+結果)
      傾斜計測.csv             ← アプリが作る(同じ内容の表、WKT列に形状)
      断面_北側の農道.csv      ← 断面を保存したとき
```

作業フォルダは Chrome・Edge で使えます。Firefox・Safari では「DEMを追加」「レイヤを追加」でファイルを選び、計測は「GeoJSON / CSV で保存」でダウンロードしてください。
DEMやレイヤは地図にドラッグ&ドロップしても読み込めます。

## 範囲の傾斜(五角形・四角ボタン)

範囲を囲むと、セル中心が範囲内にある1mセルについて次を計算します。

| 項目 | 内容 |
|---|---|
| **全体の傾き** | 範囲内の地表を**1枚の平面で近似**したときの傾き(度・%・1/n)と、低い方の向き(16方位)。棚田のように平らな田面と急な法面が混ざる所では、セルの平均よりこちらが「ほ場の勾配」に近い |
| 平面近似残差 | 平面からの標高のばらつき(標準偏差, m)。大きいほど段や凹凸があり、全体の傾きは目安になる |
| 平均・中央値・90%点・最大・最小・標準偏差 | セルごとの傾斜(Horn法・3×3)の統計 |
| 傾斜区分の割合 | 3°未満/3〜8°/8〜15°/15〜20°/20〜30°/30°以上 の面積割合(`CONFIG.slopeClasses` で変更) |
| 標高 | 最高・最低・平均・標高差 |
| 投影面積・表面積 | 表面積 = 投影面積 × 平均(1/cosθ)(RichField と同じ計算) |
| 直払の目安 | 全体の傾きを中山間地域等直接支払の傾斜基準に当てはめたもの。田:1/20以上=急傾斜、1/100以上=緩傾斜/畑・草地:15°以上=急傾斜、8°以上=緩傾斜(`CONFIG.chokubarai`)。**実際の判定方法は市町村・県の要領に従ってください** |

## ラインの勾配・断面(折れ線ボタン)

ラインを引くと、0.5m間隔で標高を取り(双一次補間)、次を計算します。ポップアップに断面図が出ます。

| 項目 | 内容 |
|---|---|
| **平均勾配** | 始点と終点の標高差 ÷ 水平距離(度・%・1/n) |
| 最大勾配 | 5m以上離れた2点の間の勾配の最大(`CONFIG.gradWindow`)。断面図に赤で表示。DEMの細かな凹凸を拾いすぎないよう区間で見ています |
| 線上の地表の傾斜 | ラインが通るセルの傾斜(Horn法)の平均・最大。ラインの向きに関係ない地表面そのものの傾き(等高線に沿った農道でも、法面の傾斜がわかる) |
| 水平距離・斜距離 | 斜距離は断面に沿った長さ |
| 標高 | 始点・終点・標高差・最高・最低、累積の上り・下り |

「断面をCSVで保存」で、距離・経度・緯度・標高・地表の傾斜・前の点からの勾配の表を、作業フォルダ(なければダウンロード)に保存します。

## そのほか

- **地点の標高・傾斜**:地図をクリックすると、その地点の標高・傾斜・勾配・向きを表示(DEM欄のチェックで切替)
- **傾斜区分図**:表示範囲の傾斜を区分ごとに色分けして重ねます(ズーム14以上。動かすと描き直し)。背景の「地理院 傾斜量図」も比較に使えます
- **レイヤ**:区画やラインをクリック →「傾斜を計算」「計測に追加」。「全地物の傾斜を計算」で一括計算し、元の属性+結果を CSV / GeoJSON で書き出し。列の値で色分け・ラベル表示もできます(RichField と同じ)
- **計測の受け渡し**:`傾斜計測.geojson` を渡し、受け取った人は「他の計測ファイルを読み込む」で追加(同じ計測は更新日時の新しい方が残ります)。保存ファイルから読んだラインの断面図は、DEMがあれば開いたときに作り直します

## DEMについて

- 座標系はGeoTIFFから自動で判定します(JGD2011/JGD2000 の平面直角座標 I〜XIX系、UTM 51〜55帯、緯度経度)。判定できないときはEPSGコードか系番号を聞かれます(長野県は VIII系 = 8)
- 黄色の点線がDEMの範囲です。範囲外では傾斜を計算できません(面積・距離だけ出ます)
- 1回に計算できる大きさは約800ha(1mDEM)まで(`CONFIG.maxCells`)
- 基盤地図情報の1mDEM(XML)は、QGISのプラグイン(QuickDEM4JP など)でGeoTIFFに変換し、平面直角座標にしておくのがおすすめです

## 計算方法と検証

- 傾斜:Horn法(3×3)。緯度経度のDEMは、範囲の中心緯度でセルの大きさをmに直して計算
- 全体の傾き:範囲内のセル中心(x=東, y=北, m)と標高に z = a·x + b·y + c を最小二乗で当てはめ、傾き = atan(√(a²+b²))
- 検証(合成DEM)
  - 10°・南東向きの平面:全体の傾き 10.00°、方位 135°、平均 10.00°、面積比 1.0154(= 1/cos10°)。南東へ100mのライン:勾配 10.00°、等高線方向:0°
  - 2°・西向きの平面:全体の勾配 3.49%(1/28.6)、直払の目安 田=緩傾斜・畑=基準未満
  - 合成棚田(畦畔検出マップのサンプル):Python(numpy)で計算した値と一致(平均 3.21°、中央値 0.7°、最大 30.46°、面積比 1.0092、平面近似 2.27°・南向き、3°未満 80.6%)

## 公開・ローカル確認

1. GitHubで新しいリポジトリ(例 `SlopeField`、Public)を作り、`index.html`・`README.md`・`tools` をアップロード
2. 「Settings」→「Pages」→ `main` / `/(root)` →「Save」
3. ローカルで確認:`python tools/serve.py` → `http://localhost:8000`

サンプルDEMを最初から表示したいときは、`data/` に置いて `CONFIG.dems` に `{ url: 'data/dem.tif', name: 'サンプル' }` を書きます。
